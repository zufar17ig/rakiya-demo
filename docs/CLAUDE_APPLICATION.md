## Draft project description (update before use)

I am building Rakiya, a short-term work marketplace intended for a small Gampaha pilot. It aims to make nearby discovery, agreed compensation, acceptance-gated contact sharing, and two-sided completion records easier for workers and small businesses. The project is currently locally tested and has not established public adoption or ecosystem dependency. I would use coding assistance to improve accessibility, language support, security, testing, and maintainability. I understand this description alone does not demonstrate eligibility for the open-source program.
